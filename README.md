# 音准大脑 NoteMaster

零基础乐理 + 视唱练耳 + 写歌训练 安卓 App。目标：把「哆来咪发嗦拉西」练成 1234567 一样脱口而出，最终能看谱、听音、写歌。

## 功能模块

| 模块 | 内容 |
| --- | --- |
| 📚 学乐理 | 8 节零基础课程：音名唱名、音高八度、半音全音、简谱五线谱、音程、调式调性、和弦、写歌七步法 |
| 👂 练耳 | 听音辨唱名 / 音名反应训练 / 旋律跟读（听旋律键盘复现），带连击与正确率统计 |
| 🎹 钢琴 | 双八度互动键盘（内置音频合成），白键标注唱名/数字/音名 |
| 🎵 歌曲 | 青花瓷、童话镇、童话、可不可以、小星星、两只老虎 简化简谱，逐句歌词+数字谱，逐句播放高亮 |
| ✍️ 写歌 | 万能和弦进行库（1-5-6-4 等 6 套，一键试听）+ 八格旋律创作板 |

## 技术栈

Kotlin + Jetpack Compose (Material 3)，minSdk 26 / targetSdk 34，无第三方音频素材（内置泛音合成音色），完全离线可用。

## 构建

```bash
gradle assembleDebug   # APK 输出在 app/build/outputs/apk/debug/
```

也可直接在 GitHub Actions 页面或 Releases 页面下载已编译 APK。

## 说明

歌曲简谱为教学简化版（统一 1=C、中音区），用于读谱与音高训练，非官方原谱。
